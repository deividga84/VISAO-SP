# VISAO-SP

Conteúdo do dataset GTA/SAMP Mobile organizado em duas variantes com a mesma base files da Data Especial 10k v1.0.

## Estrutura

- data-full/files/ — 379 arquivos extraídos do pacote Data Especial 10k.
- data-lite/files/ — cópia idêntica dos mesmos 379 arquivos extraídos.
- atualização/ — arquivos de atualização presentes no dataset original.
- reports/ — relatório final e análise comparativa.

Os binários grandes são armazenados com Git LFS.
